A11y Review Coach

Automated WCAG 2.2 AA accessibility review, powered by IBM Bob

A11y Review Coach demonstrates how IBM Bob can run a full WCAG 2.2 AA accessibility audit in minutes — reviewing a three-page sample site with parallel subagents, applying every High and Medium fix, and presenting the results in an interactive dashboard — all without installing packages or running a build step.
